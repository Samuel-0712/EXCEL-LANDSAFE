# Leadership Section — Editorial Profile Design Spec
**Project:** Excel Landsafe Travels and Tours Ltd — Website
**Location:** `/about` page, Leadership section

---

## Concept: Full Editorial Magazine Profile — not a corporate team card

Two directions were weighed for this section:

- **Compact card + "Read more" accordion** — the standard corporate team-page pattern (small photo, name, title, short summary, expandable full bio). Familiar, scannable, but an accordion is fundamentally a dashboard/FAQ interaction — it signals "UI component," which cuts against the rest of the About page's typography-led, boxless, editorial approach.
- **Full editorial profile (chosen)** — a real portrait-sized photo alongside the complete biography running as flowing text in a magazine-style profile spread, nothing hidden behind an interaction.

**Why the editorial profile wins:** the About page's whole concept is "magazine feature, not corporate template." A magazine doesn't hide half a profile behind a "read more" — it commits to the length and uses column width and typography to keep it readable. Since About is a dedicated page (not competing for homepage scroll real estate), there's no cost to letting it run long. It also gives the photo room to be a genuine portrait moment rather than a shrunk avatar — more consistent with the "distinctive, not templated" goal for this page.

---

## Layout

**Two-column spread per leader** (stacks to single column on mobile):

- **Photo column** — real portrait size, not a small circular avatar. Apply the same subtle color-grade/duotone treatment used consistently across other site imagery, so it feels part of the same visual world rather than a dropped-in headshot.
- **Text column** — name (bold serif) and title (muted body style, same treatment as testimonial attribution) at the top, followed by the full biography running at a comfortable reading width — roughly 60-75 characters per line. Do not run bio text full-page-width; constrain the column so long-form text stays readable.

**Each leader gets full width/space** — the two leaders stack **vertically**, one full profile spread after another, rather than being squeezed side-by-side. Cramming two full bios side-by-side would recreate the "too dense" problem already fixed elsewhere on this page.

**Pull-quote echo:** pull one strong line from each bio and style it as a mid-text pull-quote, matching the treatment already used for the company story section earlier on the page (oversized, centered or offset, display font). This creates a visual rhythm/consistency between sections rather than introducing a new pattern just for this one.

*Example from Oluwayomi's bio:* "Her strategic direction has... positioned it as a forward-thinking player in a rapidly changing industry."

---

## What NOT to do

- No accordion / "read more" expand — full bios run inline in complete form
- No card borders or boxes around each profile — consistent with the page's boxless approach throughout
- No side-by-side cramming of both leaders into one row
- No shrinking the photo down to a small circular avatar — it should read as a real portrait, proportionate to the length/weight of the content beside it

### Ordering note
Babatunde's bio is notably shorter than Oluwayomi's (4 paragraphs vs. 7). Since both stack vertically as full-width profiles (not side by side), this length difference is not a layout problem — each profile simply takes the vertical space its own content needs, consistent with the page's general approach of not forcing uniform heights across uneven content (same principle applied to the Services grid cards earlier in the project).
